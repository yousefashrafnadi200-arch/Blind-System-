# نظام التعرف على الوجوه

تطبيق سطح مكتب يفتح الكاميرا، يكتشف الوجوه، ويطابقها مع صور مخزّنة في مجلد `Faces/`
باستخدام **InsightFace** (نموذج ArcFace) و**OpenCV**، مع عرض النتيجة مباشرة على الفيديو.

- معاينة الكاميرا: **~30 FPS**
- زمن الاستدلال: **~200 ms** لكل فريم على المعالج (CPU)
- تحديث المربعات والأسماء: **~5 مرات/ثانية**

---

## التشغيل

أسهل طريقة — انقر مزدوجًا على:

```
run.cmd
```

أو من VS Code:

| الطريقة | الأمر |
|---|---|
| Task | `Ctrl+Shift+B` ثم **Run face recognition** |
| Debug | افتح `main.py` واضغط `F5` |
| Terminal | `.venv\Scripts\python.exe main.py` (بعد تثبيت المتطلبات) |

> ⚠️ شغّل **نسخة واحدة فقط**. تشغيل نسختين يعني تنافسهما على نفس الكاميرا وبطء مضاعف.

لإيقاف التطبيق: اضغط **Esc** أو **q** داخل نافذة الفيديو، أو أغلق النافذة.

## شرح تفصيلي

### `main.py`
- يحتوي كل الإعدادات القابلة للتعديل في أعلى الملف (الكاميرا، الدقة، المرآة، العتبة…).
- حلقة `while` واحدة: تقرأ أحدث فريم، ترسله للـ worker، ترسم النتائج، تعرض النافذة.
- `draw_results()` يرسم المربع واسم الشخص ونسبة التشابه، بلون أخضر للمعروف وبرتقالي لـ `Unknown`.
- كل ثانيتين يطبع في الطرفية:
  ```
  preview  29.9 fps | detect  5.0 fps | inference  200 ms
  ```
- في `finally` يوقف الخيطين ويحرّر الكاميرا ويغلق النوافذ — حتى عند حدوث خطأ.

### `camera.py`
- **سبب وجوده**: القراءة المباشرة من الكاميرا داخل حلقة العرض تسبب تأخيرًا، لأن تعريف الكاميرا
  يخزّن الفريمات في طابور وتُعرض فريمات قديمة.
- يفتح الكاميرا بـ `CAP_DSHOW` (أسرع على ويندوز) ويضبط `BUFFERSIZE = 1`.
- خيط داخلي يقرأ باستمرار ويحتفظ بـ **أحدث فريم فقط**؛ القديم يُهمَل تلقائيًا.
- يقلب الصورة أفقيًا (مرآة) **قبل** أي معالجة، لذلك المربعات تنطبق على الوجه بدقة.
- `frame_count` يُستخدم لحساب FPS الحقيقية للكاميرا.

### `face_recognition/detector.py`
- غلاف رقيق حول `FaceAnalysis`.
- يحمّل وحدتين فقط: `detection` (إيجاد الوجوه) و`recognition` (البصمة)، ويتجاهل
  `genderage` و`landmark_3d_68` لأنهما يضاعفان الزمن بلا فائدة هنا.
- `ctx_id=-1` يعني CPU (القيمة `0` تعني كرت شاشة رقم 0).
- `detect(frame)` ترجع قائمة كائنات `Face` تحتوي `bbox` و`embedding`.

### `face_recognition/database.py`
- `load()`: يقرأ `Faces/<اسم الشخص>/<صورة>`، يكتشف أكبر وجه في كل صورة، ويحفظ بصمته.
- **الكاش**: يحفظ البصمات في `embeddings.npz` مع بصمة (mtime + size) للملفات؛
  إذا لم تتغير الصور يُحمَّل الكاش فورًا بدل إعادة الحساب.
- **التطبيع مرة واحدة**: كل البصمات تُطبَّع وتُجمَّع في مصفوفة واحدة، فالمطابقة تصبح
  ضربة مصفوفة واحدة `matrix @ query` بدل حلقة Python.
- `recognize()` يقارن بتشابه الجيب (cosine) ويُرجع `(الاسم, التشابه)`، ويُرجع `Unknown` إذا:
  - التشابه أقل من `threshold` (افتراضي `0.5`)، أو
  - الفرق بين أفضل شخص وثاني أفضل شخص أقل من `margin` (افتراضي `0.05`) — لتقليل الخلط بين المتشابهين.
- يحسب أفضل نتيجة **لكل شخص** أولًا، فوجود عدة صور لنفس الشخص لا يخلق منافسة وهمية.
- محمي من القسمة على صفر (بصمة فارغة → `Unknown` بدل `NaN`).

### `face_recognition/worker.py`
- خيط خلفي: `update_frame()` يضع أحدث فريم، و`get_results()` يقرأ النتائج بأمان (lock).
- يعالج فقط الفريمات **الجديدة** (عبر `frame_id`)، فلا يعيد الحساب على نفس الصورة.
- يهدّئ نفسه إلى `max_fps` حتى يبقى المعالج متاحًا للعرض.
- أي خطأ في فريم واحد يُطبع ولا يقتل الخيط.
- `stop(timeout)` لا يعلّق الإغلاق.

### `Faces/`
```
Faces/
├── Ahmed/
│   ├── 1.jpg
│   └── 2.jpg
└── Sara/
    └── sara.png
```
- اسم المجلد = الاسم الذي يظهر على الشاشة.
- صيغ مدعومة: `jpg, jpeg, png, bmp, webp`.
- صورة واحدة جيدة تكفي، لكن 3–5 صور بإضاءة/زوايا مختلفة تعطي دقة أفضل.
- بعد إضافة/حذف صور احذف `embeddings.npz` أو اتركه — يُعاد بناؤه تلقائيًا عند تغيّر الملفات.

## الإعدادات (أعلى `main.py`)

| الثابت | القيمة الافتراضية | المعنى |
|---|---|---|
| `CAMERA_INDEX` | `0` | رقم الكاميرا (جرّب `1` أو `2` لو عندك أكثر من واحدة) |
| `FRAME_WIDTH` / `FRAME_HEIGHT` | `640` / `480` | دقة العرض |
| `MIRROR` | `True` | عرض مرآة. اجعلها `False` للاتجاه الخام |
| `DETECT_SIZE` | `(320, 320)` | دقة الكشف: أصغر = أسرع، أكبر = أدق |
| `MAX_FPS` | `10.0` | أقصى عدد مرات مطابقة في الثانية |
| `THRESHOLD` | `0.5` | حد التشابه لقبول الاسم (ارفعه = أكثر تحفظًا) |

## حل المشاكل

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError: No module named 'cv2' / 'insightface'` | المفسّر المختار في VS Code لا يحتوي الحزم — اختر مفسّرًا فيه المتطلبات أو ثبّتها في `.venv` |
| الصورة متأخرة/متقطّعة | تأكد من تشغيل نسخة واحدة فقط، وأن `camera.py` مستخدم |
| المربعات لا تنطبق على الوجه | لا تقلب الصورة في `main.py`؛ القلب يتم داخل `camera.py` فقط |
| `Failed to open camera` | الكاميرا مستخدمة من تطبيق آخر (Teams/Zoom)، أو `CAMERA_INDEX` خاطئ |
| بطء شديد | صغّر `DETECT_SIZE` إلى `(256, 256)` أو استخدم نموذج `buffalo_s` في `main.py` |
| يظهر `Unknown` دائمًا | أضف صورًا أوضح، أو خفّض `THRESHOLD` إلى `0.35` |
